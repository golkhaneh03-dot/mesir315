# زندگی من — نسخه HTML + ساخت APK با GitHub

این پروژه یک وب‌اپ فارسی راست‌چین با تم تیره است و برای تبدیل به APK با Capacitor و GitHub Actions آماده شده است.

## امکانات فعلی
- افزودن، حذف و تکمیل کارها
- دسته‌بندی و اولویت کارها
- شمارنده کارها و فیلترها
- عادت‌های روزانه
- ذخیره محلی داده‌ها در مرورگر/حافظه وب‌ویوی اپ
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## ساخت APK از طریق GitHub
1. در GitHub یک مخزن جدید بساز.
2. تمام محتویات این پوشه را در ریشه مخزن بارگذاری کن (مهم: پوشه `.github` هم بارگذاری شود).
3. از زبانه **Actions** گردش‌کار **Build Android APK** را انتخاب کن.
4. روی **Run workflow** بزن؛ یا پس از push به شاخه `main`، خودکار اجرا می‌شود.
5. پس از اتمام موفق، وارد اجرای workflow شو و از بخش **Artifacts** فایل `zendegi-man-debug-apk` را دانلود کن.
6. ZIP دانلودشده را باز کن؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کن.

## نکته‌ها
- این گردش‌کار APK آزمایشی (debug) می‌سازد؛ برای انتشار عمومی در مارکت‌ها باید نسخه release و امضای اختصاصی ساخته شود.
- GitHub Pages فقط نسخه وب را میزبانی می‌کند و به‌تنهایی APK نمی‌سازد؛ ساخت APK توسط GitHub Actions و Capacitor انجام می‌شود.
- برای نصب APK ممکن است لازم باشد اجازه نصب از منابع ناشناس را در گوشی فعال کنی.
- اطلاعات فعلی در حافظه محلی همان نصب/مرورگر ذخیره می‌شود؛ حذف داده‌های برنامه یا پاک‌کردن مرورگر می‌تواند آن‌ها را پاک کند.
- یادآوری زمان‌دار، تقویم شمسی، پشتیبان‌گیری و دستیار هوشمند هنوز در این نسخه پیاده‌سازی نشده‌اند و می‌توانند در نسخه‌های بعدی اضافه شوند.
